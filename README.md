🌦️ Weather App

A lightweight and responsive weather application built with HTML, CSS, and JavaScript, powered by the OpenWeather API.
It allows users to search for any city and get real-time weather information instantly.

🚀 Features

🔍 Search weather by city name

🌡️ Real-time temperature display

💧 Humidity and weather condition info

🌬️ Wind speed details

☁️ Dynamic weather icons based on conditions

❌ Error handling for invalid city names

📱 Fully responsive design

🛠️ Built With

HTML5 – Structure

CSS3 – Styling & layout

JavaScript (Vanilla JS) – Functionality

OpenWeather API – Weather data
